# Perler to Perfect

把插画、动漫图和 AI 生成图转换为可制作、可复核的生产级拼豆图纸。

项目已进入首个可运行 MVP。当前版本面向桌面浏览器并完全在本地处理图片：用户指定精确的行列数（每边最多 300 格），系统将每个非空格严格映射到一个色板色号，支持基础人工精修，并导出带逐格色号的高清 PNG 母版及含图例、分块 PNG 的 ZIP。

详细的技术决策、参考项目评估、数据模型、算法、测试与实施顺序见 [实施方案](docs/implementation-plan.md)。

## 本地运行

需要 Node.js 20 或更高版本，以及支持 `Worker`、`OffscreenCanvas` 的新版桌面 Chrome/Edge。

```bash
npm install
npm run dev
```

macOS 用户也可以双击项目目录中的 `start.command` 一键启动。脚本会自动检查依赖、启动本地开发服务器并打开 `http://127.0.0.1:5174/`。

常用质量检查：

```bash
npm run typecheck
npm run test:run
npm run build
```

## 当前 MVP 已实现

- PNG/JPEG/WebP 原图导入和精确 `1–300 × 1–300` 网格。
- 自由裁切、缩放与平移构图，不再需要单独选择原图适配方式。
- 4×4 格内取样、CIEDE2000 色差、自适应成图颜色上限和边缘感知的小连通区清理，运行在 Web Worker 中。
- 默认 104×104 网格；细节优先模式会提高轮廓与高对比小区域的权重，同时继续清理低对比杂点。
- 用色数是上限而非配额；候选色没有足够色差收益时会提前停止，并默认抑制缺乏区域支撑的相近色。
- 严格的 `EMPTY`/单色格矩阵；Canvas 逐格预览色号。
- 画笔、橡皮、平移、缩放、撤销/重做，以及可预览、可撤销的边缘背景清理。
- 内置 MARD 标准 221 色，并支持 CSV/JSON 色板导入、库存色号启用/禁用与逐色用量统计。
- IndexedDB 自动保存、工程 JSON 导入导出。
- 带坐标和逐格色号的母版 PNG；图例 PNG 与可配置分块 PNG 一起收录在 ZIP 中。

默认色板采用 [PixelBeads MARD 色卡（2026 重新修订版）](https://www.pixel-beads.com/zh/mard-bead-color-chart)中的 A–H 与 M 系列，共 221 色。数据获取日期为 2026-08-06；内置校验指纹为 `1d7467ea26695a60af845e0892a8cd99eebc1fe4f17d0a735835b2de604ed6aa`。页面提供的 HEX 是屏幕显示近似值，实体豆颜色可能受光线与批次影响。

当前导出面板提供 `29 / 50 / 75 / 100` 四种分块尺寸，并非任意 `10–100` 的自由输入。色号支持启用/禁用和锁定；RedInk 联动已实现，浏览器端到端验收仍在下一阶段。

## 已锁定的首版边界

- 独立重写，不复制 `Zippland/perler-beads` 的 AGPL-3.0 代码。
- 桌面网页、本地计算、图片不上传服务器。
- 精确宽 × 高网格，宽高分别限制在 1–300。
- 通过自由裁切、缩放和平移调整取景，直接把主体放入网格；当前默认使用 `crop` 构图。
- 面向插画、动漫与 GPT-IMAGE 生成图，不做照片抖动模式。
- MARD 标准 221 色作为默认目录目标，同时支持 CSV/JSON 自定义色板与库存子集。
- 成图默认最多使用 16 色，用户可在 2–64 色间调整，并启用/禁用或锁定色号。
- 基础精修：画笔、橡皮、撤销、重做；工程自动保存并可导入导出。
- 输出 PNG 母版、图例 PNG，以及默认 50×50 格的可配置分块 PNG ZIP（含 29×29 预设）。

## 与 RedInk 联动

系列合集的单张角色图现在提供“生成拼豆图纸”入口。RedInk 先生成无文字、无边框、单主体、有限色且轮廓清晰的拼豆源图，再通过浏览器安全交接给本工具处理；图纸生成完成后，RedInk 会先弹出确认，只有用户确认才把母版 PNG 追加为该子主题的最后一张图片。取消或关闭窗口不会改动历史记录。

本地默认使用 RedInk `http://localhost:5173` 与 Perler `http://localhost:5174`；线上部署通过精确 origin 配置互信，不使用 `*`。交接协议、回传校验、追加规则与测试口径见 [实施方案的联动章节](docs/implementation-plan.md#9-redink-系列合集联动计划)。
