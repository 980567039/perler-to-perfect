# Perler to Perfect

把插画、动漫图和 AI 生成图转换为可制作、可复核的生产级拼豆图纸。

项目已进入首个可运行 MVP。当前版本面向桌面浏览器并完全在本地处理图片：用户指定精确的行列数（每边最多 300 格），系统将每个非空格严格映射到一个色板色号，支持基础人工精修，并导出带逐格色号的高清 PNG 母版、图例与分块 PNG ZIP。

详细的技术决策、参考项目评估、数据模型、算法、测试与实施顺序见 [实施方案](docs/implementation-plan.md)。

## 本地运行

需要 Node.js 20 或更高版本，以及支持 `Worker`、`OffscreenCanvas` 的新版桌面 Chrome/Edge。

```bash
npm install
npm run dev
```

常用质量检查：

```bash
npm run typecheck
npm run test:run
npm run build
```

## 当前 MVP 已实现

- PNG/JPEG/WebP 原图导入和精确 `1–300 × 1–300` 网格。
- `contain` 补空格与居中 `crop` 两种构图方式。
- 4×4 格内取样、CIEDE2000 色差、硬性成图颜色上限和小连通区清理，运行在 Web Worker 中。
- 默认 104×104 网格；细节优先模式会提高轮廓与高对比小区域的权重，并保留 1–2 格微细节。
- 严格的 `EMPTY`/单色格矩阵；Canvas 逐格预览色号。
- 画笔、橡皮、平移、缩放、撤销/重做，以及可预览、可撤销的边缘背景清理。
- 内置 MARD 标准 221 色，并支持 CSV/JSON 色板导入、库存色号启用/禁用与逐色用量统计。
- IndexedDB 自动保存、工程 JSON 导入导出。
- 带坐标和逐格色号的母版 PNG、图例 PNG、可配置分块 PNG ZIP。

默认色板采用 [PixelBeads MARD 色卡（2026 重新修订版）](https://www.pixel-beads.com/zh/mard-bead-color-chart)中的 A–H 与 M 系列，共 221 色。数据获取日期为 2026-08-06；内置校验指纹为 `1d7467ea26695a60af845e0892a8cd99eebc1fe4f17d0a735835b2de604ed6aa`。页面提供的 HEX 是屏幕显示近似值，实体豆颜色可能受光线与批次影响。

下一阶段重点是增加交互式裁切取景与锁定色 UI，并补齐自动化端到端测试。

## 已锁定的首版边界

- 独立重写，不复制 `Zippland/perler-beads` 的 AGPL-3.0 代码。
- 桌面网页、本地计算、图片不上传服务器。
- 精确宽 × 高网格，宽高分别限制在 1–300。
- 默认等比完整放入并以“空格”补边，可切换裁切并调整取景。
- 面向插画、动漫与 GPT-IMAGE 生成图，不做照片抖动模式。
- MARD 标准 221 色作为默认目录目标，同时支持 CSV/JSON 自定义色板与库存子集。
- 成图默认最多使用 16 色，用户可在 2–64 色间调整并锁定/禁用色号。
- 基础精修：画笔、橡皮、撤销、重做；工程自动保存并可导入导出。
- 输出 PNG 母版、图例 PNG，以及默认 50×50 格的可配置分块 PNG ZIP（含 29×29 预设）。
